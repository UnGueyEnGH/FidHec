Proyectos de Desarrollo Web

Espacio dedicado a la exhibición, documentación y seguimiento de las aplicaciones desarrolladas durante el curso.

¿Qué es este portafolio?

Este portafolio digital funciona como un registro dinámico e integral de las soluciones de software construidas a lo largo de las asignaturas. Aquí se recopilan tanto el código fuente, la arquitectura de base de datos, interfaces de usuario y la lógica de negocio implementada en cada proyecto.

Su objetivo principal es demostrar el dominio técnico adquirido en el diseño, desarrollo y despliegue de aplicaciones web funcionales.

Materias y Áreas de Enfoque

Materia / Submódulo 1

Construye Aplicaciones Web

Enfoque centrado en la maquetación, diseño de interfaz (Frontend), interactividad del usuario y los fundamentos de la estructura e integración de tecnologías web modernas.

Competencias clave:

  • Diseño HTML5, CSS3 y JavaScript responsive
  • Uso de plantillas y componentes reutilizables
  • Consumo e integración de interfaces web
